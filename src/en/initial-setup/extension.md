In VS Code on Windows, press `Ctrl+Shift+X` to open **Extensions** and search for an extension below. Check its publisher and features, then select **Install** for the ones you need.

## Code Spell Checker

Underlines words that may be misspelled in LaTeX, Markdown, and code. Use it if you write in English often; you can add technical terms to its word list.

<p><a class="doc-action-link" href="https://marketplace.visualstudio.com/items?itemName=streetsidesoftware.code-spell-checker">View Code Spell Checker</a></p>

</figure>

## Bookmarks

Mark positions you want to revisit in a long file. You can jump between bookmarks or choose a position from the bookmark list.

<p><a class="doc-action-link" href="https://marketplace.visualstudio.com/items?itemName=alefragnani.Bookmarks">View Bookmarks</a></p>

<figure class="image-frame">
  <img src="/assets/images/extension-2.png" alt="Bookmarks extension">
</figure>

## Todo Tree

Finds comment tags such as `TODO` and `FIXME` across the workspace and shows them in a tree. Select an item to jump to its file and line.

<p><a class="doc-action-link" href="https://marketplace.visualstudio.com/items?itemName=gruntfuggly.todo-tree">View Todo Tree</a></p>

<figure class="image-frame">
  <img src="/assets/images/extension-3.png" alt="Todo Tree extension">
</figure>

## Code Ace Jumper

Shows keyboard targets for words or visible lines so you can move the cursor to one of them. If you use it often, assign a shortcut in VS Code’s keyboard shortcut settings.

<p><a class="doc-action-link" href="https://marketplace.visualstudio.com/items?itemName=lucax88x.codeacejumper">View Code Ace Jumper</a></p>

<figure class="image-frame">
  <img src="/assets/images/extension-4.png" alt="Code Ace Jumper extension">
</figure>

## Markdown All in One

Adds commands to create and update a table of contents, edit lists, and apply Markdown formatting with shortcuts. VS Code already includes a basic Markdown preview.

<p><a class="doc-action-link" href="https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one">View Markdown All in One</a></p>

<figure class="image-frame">
  <img src="/assets/images/extension-5.png" alt="Markdown All in One extension">
</figure>

## Julia

Provides syntax highlighting, code completion, and an integrated REPL for Julia development. Install Julia separately to run your code.

<p><a class="doc-action-link" href="https://marketplace.visualstudio.com/items?itemName=julialang.language-julia">View Julia</a></p>
