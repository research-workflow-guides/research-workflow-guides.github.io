## Download JabRef

<div class="doc-action-row">
  <p>In <strong>Download</strong> on the official JabRef website, get the Windows installer, run it, and follow the installer prompts. macOS and Linux steps will be written and verified later.</p>
  <a class="doc-action-link" href="https://www.jabref.org/#download">Official JabRef downloads</a>
</div>

<h2 id="official-tutorial">Use JabRef</h2>

In JabRef, choose **File > Open library** and open `seed-document/bibliography.bib` from the [BibTeX guide](/en/writing-in-vs-code/bibliography-citation/). Save reference edits to that file, then rebuild the manuscript in VS Code to check the changes.

<div class="doc-action-row">
  <p>JabRef's Getting started guide explains the library window and how to add and edit reference entries.</p>
  <a class="doc-action-link" href="https://docs.jabref.org/getting-started">JabRef Getting Started</a>
</div>
