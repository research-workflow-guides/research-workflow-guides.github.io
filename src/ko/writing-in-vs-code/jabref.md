## JabRef 다운로드

<div class="doc-action-row">
  <p>JabRef 공식 웹사이트의 <strong>Download</strong>에서 Windows 설치 파일을 받아 실행하고, 설치 창의 안내에 따라 설치합니다. macOS와 Linux 절차는 추후 작성·검증합니다.</p>
  <a class="doc-action-link" href="https://www.jabref.org/#download">공식 JabRef 다운로드</a>
</div>

<h2 id="official-tutorial">JabRef 사용하기</h2>

JabRef의 **File > Open library**에서 [BibTeX 안내](/ko/writing-in-vs-code/bibliography-citation/)에 나온 `seed-document/bibliography.bib`를 엽니다. 문헌 항목을 수정해 같은 파일에 저장한 뒤 VS Code에서 원고를 다시 빌드해 변경 사항을 확인합니다.

<div class="doc-action-row">
  <p>JabRef의 Getting started 안내에서 라이브러리 화면과 문헌 항목을 추가·편집하는 방법을 확인할 수 있습니다.</p>
  <a class="doc-action-link" href="https://docs.jabref.org/getting-started">JabRef Getting Started</a>
</div>
