## JabRef 다운로드

JabRef는 [공식 웹사이트](https://www.jabref.org/)에서 다운로드할 수 있습니다. 운영 체제(Windows, Mac 또는 Linux)에 맞는 버전을 선택한 후 컴퓨터에 설치하세요.

## Official Tutorial

공식 튜토리얼은 다음에서 확인할 수 있습니다: [JabRef Getting Started](https://docs.jabref.org/getting-started).

## 넘어가기 전

JabRef를 설치한 뒤에는 `references.bib`처럼 bibliography 파일을 LaTeX project folder 안에 두어 manuscript와 bibliography가 함께 관리되도록 합니다.
